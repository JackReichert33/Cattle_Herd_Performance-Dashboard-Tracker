# Cattle_Herd_Performance-Dashboard-Tracker
The Beef Cattle Performance Tracker is a Python-based data analytics project designed to evaluate and compare the growth performance of Angus and crossbred beef cattle. Using pandas, the tracker calculates total weight gain, Average Daily Gain (ADG), and individual animal performance rankings to help identify high-performing cattle.  
The project also incorporates feed cost data to support future analysis of feed costs per pound of weight gained. By organizing cattle performance data into clear summaries and comparisons, this tool aims to help cattle producers make more informed, data-driven decisions about herd management, growth performance, and feeding efficiency.

Technologies: Python, pandas, Google Colab

Key Metrics: Total Weight Gain, Average Daily Gain (ADG), Performance Rankings, and Feed Cost Analysis
